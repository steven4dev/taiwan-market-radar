⚡ 更新八大公股銀行資料

由於 wantgoo.com 的 CORS 限制，請依以下步驟手動更新資料：

步驟 1 — 在 wantgoo.com 開啟瀏覽器 Console

開啟 wantgoo 八大公股銀行頁面，按 F12 開啟 DevTools，切換到 Console 分頁。

步驟 2 — 貼上並執行以下指令

複製下方程式碼，貼入 Console 後按 Enter：

fetch('/stock/public-bank/trend-data?market=-1')
  .then(r => r.json())
  .then(d => {
    const url = 'https://steven4dev.github.io/taiwan-market-radar/update-bank.html#' + btoa(unescape(encodeURIComponent(JSON.stringify(d))));
    window.open(url, '_blank');
  });

步驟 3 — 回到此頁，資料會自動儲存

執行指令後會開啟此頁新分頁，資料自動寫入 localStorage。

等待資料...
